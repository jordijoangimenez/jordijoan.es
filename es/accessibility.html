Accesibilidad

Quiero que este sitio funcione para todo el mundo, sea cual sea el dispositivo, el navegador o la tecnología de apoyo que utilices.

Consejos para usar este sitio

  • El sitio se abre con el mismo aspecto claro u oscuro que tu dispositivo. Puedes cambiarlo cuando quieras con el botón del sol o la luna, arriba de la página.
  • Cambia el idioma con el botón del globo, al lado. Cada página tiene el mismo contenido en seis idiomas.
  • Haz el texto más grande con Ctrl y + (Cmd y + en un Mac). La página se reorganiza para que no se corte nada.
  • Pulsa Tab para pasar de un enlace o botón al siguiente. La primera parada te permite saltar directamente al contenido.
  • Abre una foto para verla más grande. Usa las flechas del teclado o desliza para ver la siguiente, y Esc para cerrar.

Estándar

El sitio aspira a cumplir las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.2 en el nivel AA.

Qué se ha hecho

  • Todo funciona solo con el teclado, con un indicador de foco visible y un enlace para saltar al contenido.
  • Las páginas usan encabezados y regiones bien definidos, las imágenes tienen texto alternativo y los lectores de pantalla avisan cuando un enlace abre una pestaña nueva o un archivo.
  • Las animaciones se desactivan cuando el sistema pide reducir el movimiento, y nada se reproduce automáticamente.
  • El texto tiene un contraste mínimo de 4,5:1 tanto en el tema oscuro como en el claro, y el sitio se adapta a los modos de alto contraste.
  • El texto se puede ampliar hasta el 200 % y el diseño se adapta hasta un ancho de 320 píxeles sin desplazamiento horizontal.
  • El sitio está disponible en seis idiomas, y el idioma de cada página, y de los títulos en inglés dentro de las páginas traducidas, está marcado para las tecnologías de apoyo.

Limitaciones conocidas

  • Los títulos de artículos, ponencias y documentos de estandarización se mantienen en su idioma original, normalmente el inglés.
  • El CV es un PDF en inglés, español y catalán. Está etiquetado para lectores de pantalla, pero un PDF nunca es tan flexible como una página web.
  • Los sitios enlazados, como editoriales, LinkedIn o GitHub, quedan fuera de mi control.

Cómo se comprueba

Cada página se revisa automáticamente con axe-core cada vez que se actualiza el sitio, y el uso con teclado se comprueba a mano.
